# 📘 Playbook de Estratégias Meta Ads (ODAX & Performance Moderna)

> **Documento de Inteligência e Melhores Práticas de Tráfego**  
> *Base de Conhecimento para o Agente e Gestores*

---

## 1. 🎯 Objetivos de Campanha (ODAX) e Quando Usar Cada Um

| Objetivo na Meta | Quando Usar | Alerta do Agente |
| :--- | :--- | :--- |
| **`OUTCOME_LEADS`** *(Cadastros / Formulários)* | Ideal para captação de contatos qualificados para **Grupos VIP de WhatsApp**. Otimiza para quem tem hábito de preencher e entrar. | Prioridade máxima para a fase atual do projeto. |
| **`OUTCOME_ENGAGEMENT`** *(Mensagens / Direct)* | Ideal para a fase de **Comentários no Post / Envio de Link por Direct**. Gera conversas no direct ou WhatsApp. | Usar quando implementar o fluxo de automação de direct. |
| **`OUTCOME_TRAFFIC`** *(Cliques no Link)* | Apenas para gerar volume bruto ou alimentar pixels novos. **Não otimiza para conversão real.** | ⚠️ Alerta: Evitar para grupos VIP, pois costuma trazer cliques ociosos e CPA alto. |
| **`OUTCOME_SALES`** *(Vendas no Site)* | Para e-commerce direto com checkout e catálogo de produtos. | Não aplicável para entrada em grupos VIP. |

## 2. 🛡️ Otimização Segura & Fase de Aprendizado

1. **Janela Mínima de Estabilização:**
   - Todo conjunto de anúncios novo ou alterado precisa de no mínimo **72 horas (3 dias)** sem novas intervenções para sair da fase de aprendizado.
2. **Variação Máxima de Orçamento:**
   - Nunca aumentar ou diminuir mais de **20% de orçamento diário a cada 24-48 horas** em conjuntos em fase de aprendizado, sob pena de reiniciar o algoritmo.
3. **Métrica de Saturação (Frequência):**
   - **Frequência 7d < 2.0:** Saudável.
   - **Frequência 7d entre 2.2 e 2.8:** Alerta de atenção (início de saturação).
   - **Frequência 7d > 3.0 acompanhada de alta no CPA:** Saturação confirmada. O agente deve sugerir pausar o criativo e ativar novo formato.

## 3. 🎨 Estratégia de Criativos para o Nicho Tech & Gamer

1. **Variedade de Formatos:**
   - **Feed (1:1 ou 4:5):** Imagens com contraste alto (estilo neon, dark mode) destacando o menor preço ou bug de valor.
   - **Stories / Reels (9:16):** Vídeos curtos de 10 a 20s mostrando a tela do PC ou unboxing de periféricos.
2. **Regra Inviolável de Transparência:**
   - **Isenção de Loja:** Deixar explícito que o grupo não é loja e não vende nada diretamente, apenas garimpa ofertas de lojas confiáveis.
